# FIFA World Cup Data Analysis ⚽

## Project Overview
This project analyzes FIFA World Cup datasets using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Includes
- Match statistics
- Goal analysis
- Attendance trends
- Winning patterns

## Dataset
- WorldCupMatches.csv
- WorldCupPlayers.csv
- WorldCups.csv
